Shadows are tokens (--shadow-sm, --shadow-md, --shadow-lg). Cards use sm at rest, md on the service hover, and lg on the venture hover.

Breakpoints

  • 900px: the main layout breakpoint. Multi-column grids become single columns and the nav collapses into the menu button.
  • 520px: the compact nav. The "Venture Studio" tag is hidden and the Connect button shrinks so the logo, Connect and menu button fit at 380px.
  • Grid auto-fit minimums: 180px (hero stats), 240px (thesis pillars), 320px (venture and service cards).

Rules

  • Use --copper-ink for copper text on light backgrounds. Use --copper only for rules, dots, borders and the button gradient.
  • Use --gold-ink for gold text on light backgrounds. Gold text on dark backgrounds uses --gold.
  • Secondary text on light backgrounds uses --warm-gray, which clears 4.5:1 on the page and on the cream sections.
  • Body text on light backgrounds uses --charcoal. Headings use --navy-dark.
  • Radius: 4px for controls and small tags, 12px for the main cards and panels, 100px only for pills.
  • Every page has one h1. Card titles inside a page use h2 or h3 without skipping a level.
  • Focus is a 3px outline. On dark sections it uses --gold.
  • Motion respects prefers-reduced-motion.

Open items

  • Homepage and blog use different palettes. Choose one navy and one copper for both.
  • Several tokens are defined but unused: --navy-mid, --gold-dim, --sand (homepage), --text-muted, --teal-light, and --copper (blog). Remove them or use them.
  • The homepage hero gradient and borders use literal values. Move them to tokens.
